关于游戏乐园

项目简介

游戏乐园是一个基于 Flask + MySQL 的休闲小游戏平台，集成了多款经典小游戏，支持用户注册登录、成绩记录、排行榜、成就系统等功能。

技术栈

  • 后端框架：Flask
  • 数据库：MySQL
  • 前端：HTML5 + CSS3 + JavaScript
  • UI设计：响应式布局，移动端适配

功能特色

  • 6款经典休闲小游戏
  • 用户注册/登录系统
  • 游戏成绩记录与排行榜
  • 成就系统
  • 个人中心与游戏历史
  • 管理后台
